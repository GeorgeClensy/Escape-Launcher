# Security Policy

## Supported Versions

We will only be supporting the latest version of the app at any point.

## Reporting a Vulnerability

If you find a vulnerability, please report it on the [security tab here](https://github.com/GeorgeClensy/Escape-Launcher/security/advisories/new) and we will get onto fixing it as fast as possible. Please give us a way to contact you about the vulnerability in your report such as an email or discord (avoid giving a phone number or WhatsApp number please).

## Disclosure Policy
Please avoid public disclosure until the issue has been resolved.
